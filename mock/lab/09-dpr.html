Retina/HiDPI ekranlarda 1 CSS pikseli = 2 (veya 1.25, 1.5, 3) fiziksel piksel. devicePixelRatio bunu söyler.

Senin ekranın: devicePixelRatio =
YANLIŞ — DPR yok
DOĞRU — DPR uygulanmış
DPR = 1 görüyorsan farkı göremezsin. Tarayıcıyı Ctrl + + ile %150'ye zoom yap ve sayfayı yenile — devicePixelRatio 1.5 olur, soldaki canvas bulanıklaşır.

Doğru yeniden boyutlandırma deseni

function resize(canvas, ctx) {
  const dpr = window.devicePixelRatio || 1;
  const r = canvas.getBoundingClientRect();   // CSS boyutu (kesirli olabilir)

  canvas.width  = Math.round(r.width  * dpr); // buffer
  canvas.height = Math.round(r.height * dpr);

  ctx.setTransform(dpr, 0, 0, dpr, 0, 0);     // scale() değil setTransform()
  //  ↑ Neden setTransform? scale() birikimlidir. resize() iki kez çağrılırsa
  //    ölçek 2×2=4 olur. setTransform her seferinde sıfırdan kurar.

  return { w: r.width, h: r.height };         // çizimde bu CSS boyutlarını kullan
}

Projede bu tam olarak overlay.js → resize() içinde. Ayrıca canvas.width'e yazmak canvas'ı temizler — bu yüzden resize'dan sonra hemen yeniden çizmek gerekir.
